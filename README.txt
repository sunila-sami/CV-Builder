# CV Builder

This is a simple web-based CV Builder application that allows users to create professional resumes quickly and easily. It offers multiple templates (modern, professional, and basic) and allows users to fill in their information to generate a CV.

## Features:
- Multiple professionally designed templates (Modern, Professional, Basic)
- Quick and easy information input
- Local storage of user data
- Download CV as PDF or print directly

## How to Use:
1. Open `index.html` in your web browser.
2. Choose a template from the available options.
3. Fill in your personal information, education, experience, and skills.
4. View your CV instantly with the chosen template.
5. Download or print your professional CV.

## Project Structure:
- `index.html`: The main landing page of the CV Builder.
- `templates.html`: Page to browse all available templates.
- `form.html`: Form for users to input their CV details.
- `css/style.css`: Custom styles for the application.
- `js/script.js`: JavaScript for application functionality.
- `images/`: Directory for any images used in the project.

## Technologies Used:
- HTML5
- CSS3 (with Bootstrap 5)
- JavaScript
